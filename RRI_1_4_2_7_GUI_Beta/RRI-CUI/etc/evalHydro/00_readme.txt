evalHydro.f90 (ver 1.0)

1. purpose: calculate Nash-Sutcliffe efficiency

2. input file : evalHydro.txt

3. format of input file

   L1 : [in] observation data file
   L2 : [in] simulation data file

4. note: time steps of observed and simulated data
         must be the same

   note2: the first columns of the data is time
          (but not read by the program)
