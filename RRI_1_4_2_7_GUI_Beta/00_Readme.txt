Before starting RRI-GUI (and RRI-CUI), please install the following libraries:
(if your PC does not have them)

1) Intel Redistributable Library Packages

    ./Presetting/w_ifort_runtime_p_2023.2.0.49500.exe


2) Microsoft Visual C++ 2015 x64 Redistributable
   
    ./Presetting/VC_redist.x64.exe

Note: vc_redist.x64.exe is regularly updated by Microsoft.

In case RRI-GUI gives any error messege when it is started, please check the latest version of vc_redist.x64 from the Microsoft webpage and and install the latest version.
